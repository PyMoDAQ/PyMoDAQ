Screenshots used by ../sequencer.rst (PNG files, to be captured from the Sequencer GUI)

Use the mock plugins with an experiment applied in the Dashboard, so that actuators, detectors and states are
available.

sequencer_main.png        Whole Sequencer window with two sequence panels: the "main" one containing a few elements
                          (Move, Repeat with Grab + Wait inside, Choice, Sequence element calling the second panel)
                          and a second panel with a couple of elements.
sequencer_add_element.png The "Add Element" button menu opened at the root level of a sequence.
elt_move.png              Move element editor with two actuators added and the hourglass (WaitForMoveDone) button
                          visible.
elt_grab.png              Grab element editor with a few detectors listed, one or two checked, Snap mode selected.
elt_wait.png              Wait element editor (time spin box in ms).
elt_repeat.png            Repeat element editor (number of repetitions).
elt_scanner.png           Scanner element editor with one or two actuators selected and a scan type configured.
elt_choice.png            Choice element editor with the "threshold" model selected so its settings show
                          (detectors, Probe Data, threshold, direction, Data0D), plus the green/red True/False
                          target combo boxes.
elt_sequence.png          Sequence element editor with the combo box listing the other sequences.
elt_state.png             State element editor with the state combo box and the "Show Manager" button.
